체크리스트1
카드 1 — 30초 핵심 규칙
하는 일
시작·조작·성공 또는 실패·다시 시작이 이어지는 한 판을 만듭니다.

완료 목표 짧은 플레이 흐름과 화면 상태를 분명하게 합니다.

첫 행동
플레이어 행동·성공 조건·실패 조건을 한 개씩 정합니다.
도형과 글자만으로 한 판을 끝까지 실행합니다.
통과 기준
T02-C01 제출한 모든 URL(결과물·소스)은 계정 생성·로그인·인증·초대·비밀번호·OAuth·CAPTCHA 없이 새 시크릿 창에서 열린다.
T02-C03 게임 규칙이 공개 화면에 보인다.
T02-C04 핵심 조작이 공개 화면에 보인다.
T02-C05 현재 게임 상태가 공개 화면에 보인다.
T02-C06 핵심 조작 한 번은 상태 변화 한 번으로 반영된다.
T02-C07 한 판은 시작 뒤 30초 안에 성공 또는 실패 상태에 도달할 수 있다.
T02-C08 성공 뒤 다시 시작하면 현재 판 상태가 초기화된다.
T02-C09 실패 뒤 다시 시작하면 현재 판 상태가 초기화된다.
막히는 지점과 확인 순서
조작이나 다시 시작이 반응하지 않습니다.
입력 초점 확인 → 이벤트 등록 횟수 확인 → 상태·타이머 초기화 확인
남길 것
한 판의 시작·진행·종료·재시작

완료 목표 입력과 시간 상태가 화면 조건 변화에도 안정적으로 이어지게 합니다.

첫 행동
다섯 검사 범주에 예상값을 적습니다.
두 해상도와 10분 실행까지 하나씩 수행합니다.
통과 기준
T02-C10 1366×768에서 조작 영역 잘림과 가로 넘침이 0건이다.
T02-C11 1920×1080에서 조작 영역 잘림과 가로 넘침이 0건이다.
T02-C12 1초 안에 같은 핵심 입력 이벤트 10건을 보낸 검사에서 이벤트 한 건당 핵심 동작이 정확히 한 번 반영된다.
T02-C13 창 크기 변경 뒤 게임 상태와 조작이 유지된다.
T02-C14 포커스 이탈과 복귀 뒤 게임 상태와 조작이 유지된다.
T02-C15 일시정지 중 상태가 진행되지 않고 재개 뒤 이어진다.
T02-C16 10분 연속 실행 뒤 게임을 계속 조작할 수 있다.
T02-C17 10분 연속 실행 뒤 브라우저 콘솔 빨간 오류가 0건이다.
막히는 지점과 확인 순서
복귀 직후 실패하거나 입력이 중복됩니다.
이탈 중 타이머 정지 → 재개 기준 시각 → 이벤트 누적 여부

통과 기준
T02-C18 변경 전 같은 설정으로 플레이한 기록이 10회 있다.
T02-C19 변경 후 같은 설정으로 플레이한 기록이 10회 있다.

막히는 지점과 확인 순서
여러 값을 함께 바꿨습니다.
변경 전 복원 → 값 하나 선택 → 나머지 고정 뒤 재실행

완료 목표 새 판 초기화·재접속 보존·손상 복구를 함께 확인합니다.

통과 기준
T02-C22 새 게임에서 현재 판 값이 초기화된다.

T02-C25 손상된 저장값에서도 게임이 중단되지 않고 선언한 기본값으로 시작한다.

손상 값에서 게임이 멈춥니다.
형식 검사 → 기본값 선언 → 상태·화면·타이머 함께 초기화

완료 목표 효과가 정한 사건에서만 실행되고 즉시 줄거나 멈추게 합니다.

첫 행동
성공·실패·충돌 중 효과를 줄 사건 하나를 고릅니다.
음소거 또는 움직임 감소를 켜고 같은 사건을 다시 시험합니다.
통과 기준
T02-C26 선택한 효과는 선언한 사건에서만 실행된다.
T02-C27 음소거 또는 움직임 줄이기를 켜면 해당 효과가 즉시 줄거나 멈춘다.
T02-C28 공개 화면과 제출물의 개인정보가 0건이다.
T02-C29 공개 화면·배포 파일·제출물의 비밀값 원문이 0건이다.
T02-C30 짧은 확인 방법에 ① 어디로 가나요, ② 3단계 이내 무엇을 하나요, ③ 무엇이 보이면 통과인가요, ④ 안 될 때 무엇이 보이나요가 구분되어 있다.
T02-C31 제출문에 ① AI에게 맡긴 일, ② 학생이 직접 판단한 일, ③ AI 제안을 따르지 않은 일(없으면 없었던 이유)이 구분되어 있다.
